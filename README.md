# GenWanMin-webfont
本專案為源雲明體（GenWanMin）的非官方woff2版，提供jsDelivr網址以便嵌入進CSS。

原作者：ButTaiwan（But Ko）
```
***Regular字重，TC字型***
@font-face {
  font-family: "GenWanMin";
  font-display: swap;
  font-weight: 400;
  font-style: normal;
  src: url("https://cdn.jsdelivr.net/gh/EOZStudio/GenWanMin-webfont@v1.0.0/GenWanMin2TC-R.woff2") format("woff2");
}

***Medium字重，TC字型***
@font-face {
  font-family: "GenWanMin";
  font-display: swap;
  font-weight: 500;
  font-style: normal;
  src: url("https://cdn.jsdelivr.net/gh/EOZStudio/GenWanMin-webfont@v1.0.0/GenWanMin2TC-M.woff2") format("woff2");
}
